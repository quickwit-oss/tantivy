# Blockwise linear V1 fixtures

These columns contain the values generated by `get_data()` in
`../bench_column_values_get.rs`, with the `i64`, `f64`, and `DateTime` conversions
from that benchmark's `main()`.

They were generated once using the former benchmark's `to_v1` helper: serialize
as V2, preserve the stats and bitpacked residuals, and rewrite only the block
metadata into V1. V1 remains read-only; the benchmark loads these fixtures through
public codec dispatch instead of maintaining a format converter or writer.

The benchmark checks every value and a full-column `get_range` against its input
before timing. If the dataset or its conversions change, update these fixtures.
