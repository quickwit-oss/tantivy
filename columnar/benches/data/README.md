# Benchmark data

`apache_2k_messages.txt` holds the messages of the 2,000 lines of `Apache/Apache_2k.log`, from
the loghub collection of system logs: https://github.com/logpai/loghub. The leading `[..]`
attributes of each line (date, level) are removed.

The loghub datasets are freely available for research or academic work. Any usage or
distribution must refer to the loghub repository: https://github.com/logpai/loghub
